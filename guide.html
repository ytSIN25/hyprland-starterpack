No keybind matches that.

Change keybinds

All keybinds live in one file. Hyprland reloads it as soon as you save.

  1. Open the binds file in any editor: 
    nano ~/.config/hypr/modules/binds.lua
  2. Find the line for the shortcut you want to change and edit the key part. Each bind has the form hl.bind("KEYS", action). For example, to open the terminal with Super+Enter instead of Super+Q: 
    -- before
hl.bind(mainMod .. " + Q", hl.dsp.exec_cmd(terminal))
-- after
hl.bind(mainMod .. " + RETURN", hl.dsp.exec_cmd(terminal))
  3. Save. If nothing happens, reload by hand and check for errors: 
    hyprctl reload
hyprctl configerrors

Add a new shortcut

Add a line anywhere in binds.lua. Some patterns you can copy:

-- Launch an app
hl.bind(mainMod .. " + E", hl.dsp.exec_cmd("firefox"))

-- Two modifiers
hl.bind(mainMod .. " + SHIFT + E", hl.dsp.exec_cmd("code"))

-- Works on the lock screen and repeats while held (good for media keys)
hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+"),
        { locked = true, repeating = true })

-- Open a Quickshell panel
hl.bind(mainMod .. " + I", hl.dsp.exec_cmd("qs ipc call panel settings"))

Change wallpaper

Images (.png, .jpg, .gif) and videos (.mp4) both work. Picking a wallpaper also recolors the bar, launcher, and terminal to match it.

The picker easiest

  1. Press Super+W. A carousel of your wallpapers opens.
  2. Scroll or use the arrow keys, then click or press Enter to apply. Esc closes it.

Add your own wallpapers

Copy files into either folder. The picker finds them on its next open:

~/.config/wallpapers/
~/Pictures/Wallpapers/
cp ~/Downloads/my-wallpaper.jpg ~/Pictures/Wallpapers/

From the terminal or a script

qs ipc call wallpaper set ~/Pictures/Wallpapers/my-wallpaper.jpg
qs ipc call wallpaper get

Auto-rotate, transitions

Open Settings from the bar (or qs ipc call panel settings) → Wallpaper. Set a rotation interval in minutes, random or in order, and the transition type and speed.

Lock screen and login screen

Lock screen (Super+L): edit the path = line under background in ~/.config/hypr/hyprlock.conf. The round picture under the clock is ~/.face; replace that file to change it.

Login screen (only if you said yes to SDDM during install): press Super+Shift+W and pick a wallpaper. If you skipped it, install it any time:

sudo pacman -S --needed sddm qt6-declarative
sudo ~/.config/sddm-launcher/install.sh
sudo systemctl enable sddm

Optional extras for your laptop

The base install works on any machine. These packages add brand-specific controls: fan curves, battery charge limits, keyboard lighting, GPU switching. Install only the one for your laptop.

You can re-run the installer just for these: ./install.sh --no-packages skips the base packages, and ./install.sh --brand asus adds the extras for one brand. Or copy the commands below. Packages marked AUR install with yay, which the installer set up for you.

Every laptop

PackageWhat it does
sof-firmwareSpeakers and microphone on most laptops from 2019 on. Installed by default.
fprintdFingerprint reader. Enroll with fprintd-enroll.
iio-sensor-proxyAuto-rotate and ambient light sensor on 2-in-1s.
thermaldKeeps Intel CPUs from overheating and throttling hard. Intel only.
intel-media-driver / libva-mesa-driverHardware video decoding (Intel / AMD), so videos and video wallpapers use less battery.

By brand

ASUS

ROG, TUF, Zephyrus, Strix, Flow

  • asusctl: keyboard RGB, fan curves, battery limit, power modes
  • rog-control-center: a GUI for all of the above
  • supergfxctl AUR: switch GPU mode (Integrated / Hybrid)
  • Stop at 80% to protect the battery: asusctl -c 80
  • Keys lagging or sticking? sudo systemctl restart asusd
sudo pacman -S asusctl rog-control-center
yay -S supergfxctl
sudo systemctl enable --now supergfxd

Lenovo Legion

Legion 5 / 7 / Pro, LOQ

  • lenovolegionlinux AUR: fan curves, power mode (Fn+Q), battery conservation
  • Then connect it to the bar's battery panel (fan curve + Performance mode) with the included script
sudo pacman -S linux-headers
yay -S lenovolegionlinux-dkms-git lenovolegionlinux-git
sudo bash ~/.config/quickshell/scripts/setup-fan-power.sh

Lenovo ThinkPad / IdeaPad

T, X, P, E series, IdeaPad, Yoga

  • acpi_call-dkms: battery charge thresholds on older ThinkPads
  • tlp: deeper battery tuning. Conflicts with power-profiles-daemon; the bar's power-mode button needs the latter, so pick one
  • thinkfan AUR: custom fan control (needs a config)
  • IdeaPad battery conservation (stops at ~60–80%):
sudo pacman -S acpi_call-dkms fprintd linux-headers
# IdeaPad: 1 = on, 0 = off
echo 1 | sudo tee /sys/bus/platform/drivers/ideapad_acpi/VPC2004:00/conservation_mode

Framework

Laptop 13 / 16, Laptop 12

  • framework-system: battery charge limit, LEDs, firmware info
  • fprintd: the power-button fingerprint reader
  • iio-sensor-proxy: ambient light sensor
  • Charge limit: sudo framework_tool --charge-limit 80
sudo pacman -S framework-system fprintd iio-sensor-proxy

Dell

XPS, Latitude, Inspiron, Alienware

  • thermald: better thermals on Intel models
  • dell-command-configure AUR: BIOS settings from Linux, including battery charge mode
  • Charge limit: sudo cctk --PrimaryBattChargeCfg=Custom:50-80
sudo pacman -S thermald
sudo systemctl enable --now thermald
yay -S dell-command-configure

MSI

GF, GS, Katana, Stealth, Raider

  • isw AUR: fan control and Cooler Boost through the embedded controller
  • Needs ec_sys write support: add ec_sys.write_support=1 to your kernel parameters
yay -S isw

Acer & others

Nitro, Predator, Aspire, HP, Huawei…

  • nbfc-linux AUR: notebook fan control with ready-made profiles for hundreds of models
  • Find your model's profile with sudo nbfc config -r
yay -S nbfc-linux
sudo nbfc config -r
sudo systemctl enable --now nbfc_service

Any laptop with an NVIDIA GPU

Intel/AMD + NVIDIA hybrid graphics

  • nvidia-open-dkms: the driver (RTX 20-series and newer)
  • nvidia-prime: run one app on the NVIDIA GPU with prime-run app
  • The bar's GPU button can also send apps to the NVIDIA GPU
  • envycontrol AUR: turn the NVIDIA GPU fully off for battery life
sudo pacman -S nvidia-open-dkms nvidia-utils nvidia-prime linux-headers
# reboot afterwards

If you use linux-lts or linux-zen instead of the default kernel, install the matching headers (linux-lts-headers, linux-zen-headers) for anything ending in -dkms.

Advanced extras (not installed by default)

These are in ~/.config/starterpack/extras/. Read the files before running them.

  • firewall/: an nftables firewall you can toggle from the bar. Installs system rules and a polkit rule, so it needs sudo.
  • workstation-mode/: an overview that shrinks the current window and shows the others as cards. See its INSTALL.md.
  • legacy/: Waybar and SwayNC configs, if you prefer them to Quickshell.
